Rocket Adventure – Kids Space Game
====================================

How to run:
1. Extract the ZIP file.
2. Open the rocket_adventure_kids folder in Visual Studio Code.
3. Open index.html with Live Server (or double-click index.html).
4. Choose an age group, rocket color and fuel amount.
5. Press "جهّز الصاروخ وانطلق".
6. Press "ابدأ الطيران".
7. Move the rocket with the on-screen arrows or keyboard Left/Right.
8. Collect the required stars and avoid asteroids.

Files:
- index.html: game structure
- style.css: visual design and responsive layout
- script.js: game logic

The game uses no external game engine. An internet connection is only needed for the optional Google font; it falls back to system fonts.
